什麼是架構?

2024-09-30

| 「我思故我在」 法國哲學家 勒內·笛卡兒 (1596-1650)

我最新影片跟文章，都有強調過「架構」的字眼多次，是時候來定義我提出的架構。

這字眼可有不同的演變。有人名為：系統、矩陣、宇宙... ....

90年代末電影代表作會名為 : The Matrix, The Thirteenth Floor

現實知名駭客 Geohotz、McAfee 會名它做 The System / The Matrix

在財商上，富爸爸·窮爸爸的作者 Robert Kiyosaki 仍稱它為 System

在創科上，Elon Musk 會稱它為 Simulation ... ...

它們幾乎上都指向同一樣事情：

如果你感覺到你生活某方面被限制了，你就是活在架構內。

這不關乎任何因素，包括於政治、法律、道德等層面。

只要你認為，你在某方面不能發展你的所長，你便是在架構內。

當 Neo 第一次被 Morpheus 解說什麼是 Matrix 的時候，

他說 The Matrix is everywhere.

你可以在日常種種生活層面上接觸到它，

包括你打開電視的時候、交稅款的時候、去工作的時候、去教堂的時候... ...

然後便是最為人知的一幕。

身邊的人會說我太過瘋狂認真去對於這部電影加而解說並散佈。

我心裡往往意思是，看看你活得多不自由。

因為你還活在架構內，你還沒準備回到現實。

電影中裡的現實，是人類被人工智能操縱的世界。

這裡會有人再三研究這電影的細節，說 Oracle 跟 Architect 才是真正的贏家。

是真的，對我來說。

但這不是我想強調的部份。

是的，他們建造了 Matrix 而 Oracle 引導所有人去執行應該走的道路，

而繼續讓這人工智能的世界繼續運行，

而 Neo、Trinity、Morpheus 只不過是這 Matrix 第 X 的版本而不斷循環，

而正正第四集的 Matrix 證實了這結論。

當你把這四集重覆研究過後，這看似來是非常黑暗的電影，

我們所有人最後是被控制了，而被 Unplug 的船員，只不過是架構上的棋子。

而我正正要帶出這黑暗的事實給你知道，

你生存在這世界、宇宙、地球、萬物上，無論你想怎樣命名它，你是永遠被這事物受控制。

看看，你是什麼生物。

你只是人類。你只不過是在宇宙內的地球經過45億年後，經細菌演變出來的多細胞生物而已。

看看你的皮膚裡有多麼細小的毛孔，散發着惡臭及流出混濁水份。

為什麼我想你強調這些事情，是因為這就是你。

我們基本上是一樣的。

就是這樣。

你以為用上化學成份的沐浴露便可以洗掉你是誰?

暫停你對你自己的欺騙吧。

我們基本上都是一樣，

直到人們開始要將所有事情要劃清界線，

他們便以為自己是不一樣，他是與眾不同。

他們開始幫自己分類，

然後建立不同社群，

並且佔領地球上土地的一切，

然後建立種種勢力，去廝殺搶奪另一方的勢力。

若果時光機真的存在，拜託你回到希特勒身邊，用盡一切努力勸阻他收手。

看看你今天在何方勢力上。

你的身體不用從軍入伍。問問你的思想，你思想屬什麼政派的。

如果你的答案，是有答案的話，拜託，你跟上面的人有什麼分別。

我們基本上是一樣的。

這世界從來是沒有任何的分類，

更加無任何的派系。

只有覺得自己不一樣的人才會去篩選。

看看現代的工作環境，

為什麼你要對着一個，根本不懂你所認識的領域上，的面試人員，

為什麼你要展示你的技能給他看，而他根本不懂這些技能，

看看他的臉，是多麼高傲，幾乎以為自己是這公司內的 CEO。

直到你在這工作環境內，

為何你要為你的上司報告種種的一切?

為什麼你的上司是，你的上司?

為什麼你要被他指派任務去進行一些你厭倦的事情?

這裡究竟發生了什麼？

你說你為了，收入?

那，什麼是收入?

你需要收入去維持生活?

什麼類型的生活方式要你把靈魂賣給你的上司?

你的歷史老師為什麼不教你，究竟石器時代的裡面的人，是怎樣生活的?

我看不到那時候需要有什麼的面試官，批准你去加入哪家公司，才可以去狩獵。

那為什麼，你需要把你的靈魂賣給你的上司?

你說你已經建立了家庭，

有妻兒而照顧，有房租要交付。

那，石器時代的裡面的家庭，是怎樣生活的?

我怎看不到他們要為了家庭而要崇拜於某一勢力。

究竟是你擁有你的家庭，你擁有你的合法伴侶跟孩童，

還是你的勢力或是國家擁有了你們的家庭。

想一想，由你誕生的那一刻，究竟誰操縱着你的童時。

再想一想，你所購買的所有身邊事物，包括你的電腦、智能手機、所有月費計劃、房屋等，

有哪一樣真正屬於你的，還是，你只是用另一個名義去租借了它們。

你對你所購買的事物有多麼的熟悉?

它會在你不知覺的情況下，出賣你嗎?

當你知道了更多這些歸根究底後，你會發現你浪費了你人生的一大段時間。

有些人早在童年時醒悟，

有些人可能在剛步入成年前，

有些人可能在建立家庭後，

有些人可能在老人階段，

有些人可能一輩子都不會醒悟。

我事實上在幼稚園時已有感覺，

經常地問自己，究竟在我有記憶之前，是誰操縱着我的身體，

我幾乎對3歲以前的事，完全不記得。

直到國小，我對教育制度已經反感，

我討厭這裡的一切，

如果現創業家有大學輟學的趨勢，

我想我國小已經有這想法。

我在那時候已經會想辦法逃學。

直到高中，這問題仍然持續，而且我的逃學手法更加反傳統。

如果「駭進學校系統，然後矇騙到缺席學生是有上學」是一件可行的事情，

那我應該能把它拍攝成電影內容。

另外我幾乎無出席到大學試。

為什麼你要給幾千塊，讓別人去決定你的成績，

而只有這些我幾乎不感興趣的科目，

儘管所謂的選修科，亦只不過是場騙局。

你們足足浪費了我三年去跟你們玩鬼抓人的現實遊戲。

而同時間，在這時候，我建立了我的頻道。

我直播着沒有人看的直播，

我建立着沒有人看的頻道，

直到我把 Juking Mindset 認真看待，

直到我成為了 Juker去教導別人怎樣脫離架構，

而創立到自己的社群，

我才真正發覺，架構的一回事。

我可能遲了，但由我童時，我一直知道這身邊的一切都是不對勁。

我學識嘗試逃離這架構，

直到將身邊種種的架構，真正脫離，我才是我自己。

我才能回到真正的我。我們基本上是一樣的。

世界是建立於創造與演變之中，

而架構是與世界成相反，

它是建立於規矩跟條件下，

你一日被它綁上，你一日不能做回自己，

直到你將身邊的一切放棄，

包括人和物，

當只有剩下你自己的時候，

你才會知道究竟自己是誰，

這是很困難的過程，

但當你被架構綁到連自我都幾乎失去的時候，

只有你的靈魂會為你發出最後的叫聲，

細心聆聽你的靈魂，除掉身上所有的一切，只有它是最為最要。

記得，我們只不過是人類，

但比起生物，我們唯一獨有的，便是靈魂。

很多人願意把靈魂賣給架構，

但看到這裡的你，並不是。

即使結局看似如此黑暗，人們最終無法脫離所有的架構，

但是，視察周圍有什麼架構你是可以掌握的，

嘗試擺脫它，

什至利用它，

讓它成為你的優勢。

專注在你能掌握的架構上，

才是生活，而不是，生存而活。

想像一下在 The Thirteenth Floor 的道格拉斯跟大衛，

若沒了靈魂地活着，跟真人的大衛又有何用處。
