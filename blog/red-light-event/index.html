黎明死線

紅光事件

2024-09-14 · 15 min read

··· ··· 事件已過 2190 日，我只能做的是——體諒他們。

那是一個風和日麗的下午，我帶着前幾晚做影片的睡意到這天，睡到不知何時。一覺醒來，仍在電腦桌面上，看到 Discord 左邊欄都區被無數的朋友私信佔滿，然後當我把它們快速查閱，發現都是叫我去黎明死線的巴哈姆特論壇上（巴哈）。

板區都被洗滿同類似的標題，如果海嘯能發生在網絡上，這裡可以是其一現場。

發佈時間今天早上，瀏覽數已過萬，成為板內當時有史而來最多人看的文章。標題是大約這樣「一群清流直播主原來都是改檔仔」。

內容是，一大堆中小型的圖奇直播主被以公審形式，截圖上來，然後內文還附 Google Sheet 作為記錄「證據」。當然我是被排在第一位。

那刻我沒急於想回應，只是懷着既可笑又難過的心情。有些主播我完全不認識，但我知道他們有些在線觀看人數也只少達 3 位數，有些的，可能是小型台主，以直播自己遊玩紀錄為主，有些的是我認識的好友。

如果說那年之前的人生，我做過最蠢的事，就是不知情下讓這些台主被加害了。我看到他們被惡意攻擊，在本來已經沒什麼觀眾的情況下，還被這樣打擊，我可說句，我有點愧對他們。

對於我自身的形象，有人仍會出現來幫我護航，但我其實不太介懷。作為這類公眾人物，小事經常被化大。

如果他們認為這種公審的形式，可以把「犯人」繩之於法，那世界還需要法律幹嘛？

有些自以為是的正義英雄，還把某些主播的背景翻了出來，我倒是不見怪，而問題是，風向居然被這群人帶動。但我當慢慢滲透在圈裡面更久了，才發現這不過都是一群烏合之眾在圍爐。

巴哈姆特與「自由」

經過這件事後，連當時的板主都自行退了下來，對，連他都被加害，然後由新的上任。

由這一刻開始，你所認知的網絡言論自由，就真的相當「自由」了。

黎明死線的巴哈，只不過另外一個「架構」而已，裡面由上到下的都是大眾。

有些我曾覺得可惜的是，某些的具權力的他們都曾是我的追隨者，最後都轉變成他們。

更多的詳情，我會在另一文章再作延伸。

在這件事裡面，隨波逐流的大眾，根本都當了自己是法官。

關於「改檔」

雖則我把紅光影片下架了，但我已經再三強調過，我影片的用意是把你的電腦效能最大化，然後我有再三聲明我的用意，而且是公開公源地指出用途，而不是販售規避服務／軟件為利是圖。

而有追隨過我直播台的觀眾都知道，你來我台，不是來看我溜板區的或是玩殺手的。

而且重點是在我直播早段其間，在 2.0.0 版本，我筆記型電腦當開上了黎明死線後，是連基本 30fps 都達不到，QTE 都不只是你想像的簡單的按不準了。

讓你想像一下，你自帶了兔子的滿階搖籃曲技能，在有舊時的厄咒：毀滅的環境下，我可以怎樣直播着遊玩這遊戲。

基於這問題，我便找出了簡單辦法，便是把 Engine.ini 有關環境的特效都設成 = 0，這裡面包括了遊戲地圖內的煙霧。

這設定是基本 Unreal Engine 內的基本設定（Unreal Engine Configuration Files），你儘管在遊戲內改個屏幕分辦率，也就是暗地裡改了這類型的文檔。

而我影片裡亦曾提到是基於 Bucket_BHVR 在 Reddit 的發佈而進行更改（Reddit — Bucket_BHVR 關於 custom user settings 的發佈）。

Bucket_BHVR: “We disabled the editing of a couple settings directly in the .ini file that were granting players an unfair advantage over other players.”

基於這說法，我是沒可能接獲到「unfair advantage」的行為。因此我的影片內容跟行為是基於研究及資料收集而製作出的。

然後我把「教學」公開公源地發佈在我頻道裡。短時間內已經吸納了不少觀看人次。

當「法官」出現

本來影片的回應都是正面的，直到這些「法官」的出現。

他們會有一大堆所謂的證據，只不過都是，直播主的紅光變亮跟沒煙霧的截圖，以及一個相當可笑而被大眾認為受權威性的對話——與官方人員的對話截圖。

裡面內容大約是，某位法官向某位官方人員詢問以上是否作弊行為，他回答是。然後就被當作論據放了上來。

我相信我儘管不在人世，我也會為這些大眾感到可笑又可悲。

他們一來花那麼多時間跟精神，去處理這麼充分的「證據」但都是仍沒有半個「犯人」被曾封鎖過；二來這位所謂的官方人員，只不過是位 Community Ambassador，你說他是位 Moderator 我也服，你搬位管 Community 的人，他連 Ban 人資格都沒有。

而他自己連官方內部的 Community 都管理不善的人出來，截一句這樣的話就認為是具說服力，跟推銷員在街邊說這產品怎麼好有啥分別。

可悲又可笑的大眾，你們真叫人可憐又可愛。

事後

事後不知隔了多個版本，官方雖則暗地裡把這設定改掉，也沒有登錄在 Patch Note 裡，經我逐一查問，也沒有半個相關我所知的「名單」人士被封鎖。

你可知這究竟弄了場什麼樣的大龍鳳。

這就是我強調過的「架構」。

你依賴於它而去改變自己？這不是我的作風，這也不是我。

我是雷姆。
